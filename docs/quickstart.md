# Quickstart

This guide is for users who want to learn the app quickly before working with their own files.

## Fastest Path

1. Start the application.
2. Open `Files -> Load Demo/Test Signal` and choose a demo dataset.
3. Select the newly loaded dataset in the dataset list.
4. Check the `Preview` tab and the overview plot.
5. Open the `Roles` tab and confirm the important columns make sense.
6. Go to `Prepare`, choose an output name if needed, and click `Create Dataset`.
7. Open `Analysis -> Open Analysis Workspace` for the prepared dataset.
8. In the analysis workspace, choose the active analysis column and use the `Frequency` tab or other tools.

## Recommended First Demo

Use the spectral demo if you want to test frequency analysis first. It is the most direct path to checking FFT amplitude or Welch PSD behavior.

## What To Expect

- The main window is where you load data, check it, and prepare it.
- The visible overview plot range is the output range for prepared datasets.
- Creating a prepared dataset adds a new dataset inside the app. It does not automatically save a new file to disk.
- The analysis workspace is where you do the deeper analysis work and exports.
