# Screenshot Plan

This repository now reserves `docs/images/` for screenshots that show the current UI and workflow.

## Suggested Captures

- main window with a loaded dataset
- preparation view showing the left-side preparation controls and the right-side preview tabs
- preparation view with the `Table` preview tab open and scrollbars visible
- analysis workspace overview
- frequency tab with FFT or Welch PSD result
- cycle-analysis related view once that workflow is more complete

## Naming Convention

Use stable descriptive names such as:

- `main-window.png`
- `prepare-view.png`
- `preview-table-tab.png`
- `analysis-workspace.png`
- `frequency-tab.png`

## Notes

- Prefer screenshots from demo datasets when possible so the visuals are reproducible.
- Capture the app at a readable scale and avoid personal file paths when practical.
- After images are added, the README can embed the most representative ones directly.
