# Glossary

## Active Analysis Column

The main column currently targeted by analysis actions in the analysis workspace.

## Analysis Workspace

The second-stage window used for detailed filtering, derived signals, spectral analysis, statistics, and export of one selected dataset.

## Column Role

A semantic label assigned to a column so the app understands its purpose.

## Frequency Analysis

Tools that describe the spectral content of a signal, currently focused on FFT amplitude and Welch PSD.

## Metadata Column

A column that is kept as descriptive context rather than treated as a primary signal.

## Output Range

The visible range in the overview plot that defines which rows will be used when creating a prepared dataset.

## Prepared Dataset

A derived dataset created from a selected source dataset using the current output range and optional channel selection.

## Preview

The quick table and plot view used to inspect the currently selected dataset before deeper analysis.

## Signal Column

A column that contains a measured or derived signal suitable for plotting and analysis.

## Time Column

A column that represents time or sample progression and is useful as an x-axis reference.

## Welch PSD

A spectral estimate that averages over overlapping windows, usually producing a smoother result than a direct FFT magnitude plot.
